# finite-size-scaling skill starter

This is a starter package for building a general-purpose finite-size-scaling Agent Skill.

Start here:

1. Read `RESEARCH_PLAN.md`.
2. Read `SKILL.md`.
3. Put the five primary papers in `papers/` if available.
4. Ask the local Agent to execute Milestones 1 and 2 first.
5. Do not implement advanced BKT/log/crossover modules until the ordinary FSS core and synthetic tests pass.

This starter package intentionally contains the scientific architecture and implementation plan but not a finished numerical backend.
